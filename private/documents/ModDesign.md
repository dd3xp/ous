# 草药学

添加6种草药，可以用来制作工具、药水、合成装置、附魔装置、刷怪装置、物流装置。

## 方块

### 木头

- [x] **红樱木原木**：可以合成红樱木木板、用红樱木木板合成红樱木木棍。
  - [x] **红樱木树苗**：红樱木的树苗。
  - [x] **红樱木木板**：用来制作本模组的合成和生产装置。
  - [x] **红樱木木棍**：用来制作本模组的工具和武器。
    - [ ] **魔法木棍**：升级版的红樱木棍
    - [ ] **繁花木棍**：比魔法木棍更高级的升级版的红樱木棍
  - [x] **红樱木树叶**：破坏或者自然凋零后概率掉落红樱木树苗和红樱桃果，底部可以用于种植红樱桃果。

### 石头

- [x] **微光石**：类似于红樱木，是本模组的石头变体。发出亮度7的微弱光芒。
  - [x] **微光石砖**：微光石的石砖形态。发出亮度7的微弱光芒。
    - [x] **符文石砖**：上有符文的微光石砖。发出亮度15的强光（和萤石一样）。
    - [x] **微光石砖台阶**：微光石砖的台阶状态。发出亮度7的微弱光芒。
    - [x] **微光石砖楼梯**：微光石砖的楼梯状态。发出亮度7的微弱光芒。

### 沙土

- [ ] **繁茂土**：不需要耕即可种植作物，还可以放到盆栽里面用来培育幼苗。有两种属性，分别为生长时间和产物掉落。通过对繁茂土使用繁茂之种改变。
  - [ ] **繁茂之种**：靠开箱子，击杀怪物，和农民交易获得，和繁茂土一样有两种属性。对繁茂土右键会消耗并将繁茂土的这两种属性变为繁茂之种的数值，用织流环shift右键可以将繁茂之种取出并重置繁茂土的两种属性为默认值。散落在箱子，怪物和农民处的繁茂之种属性均各不相同，在铁砧处可以将两个繁茂之种合成成属性更高的繁茂之种，合成时的属性增加需要满足：数值相近的属性增加的多，数值相远的属性增加的少，数值越高的属性增加的越少，需要自己拟定函数。
    - [ ] **生长时间**：默认为1，最高为1，最低为0.125，使作物的生长时间*对应数值
    - [ ] **产物掉落**：默认为1，最高为8，最低为1，使作物的产物掉落*对应数值

  - [ ] **治愈花**：用来制作绒甲

- [ ] **花束**：需要每种草药产物各1个，用来制作后期产物

## 草药

### 主世界草药

- [x] **鳞叶草（Scleris）**：生成在主世界的植物，会发出微弱的光。
  - [x] **鳞叶草籽**：可以用来种植鳞叶草作物。
  - [x] **鳞叶草作物**：有4个生长阶段，成熟后可以收获1个鳞甲和1个鳞叶草籽。
  - [x] **鳞甲（Scaleplate）**：鳞叶草的叶子，非常坚硬且蕴含着生命的脉动，用于制作装备、工具，特点是这种草药参与制作的工具和装备可以自动恢复耐久。
- [x] **雨露花（Dorella）**：生成在主世界的植物，会发出微弱的光。
  - [x] **雨露花籽**：可以用来种植雨露花作物。
  - [x] **雨露花作物**：有4个生长阶段，成熟后可以收获1个灵瓣和1个雨露花籽。
  - [x] **雨露瓣（Dewpetal）**：雨露花的花瓣，用于制作药水相关的物品。
- [x] **和风铃（Sephrel）**：生成在主世界的植物，会发出微弱的光。
  - [x] **和风铃花籽**：可以用来种植和风铃作物。
  - [x] **和风铃作物**：有4个生长阶段，成熟后可以收获1个流风花和1个和流风花籽。
  - [x] **流风花（Zephyr Blossom）**：和风铃的花朵，用于制作精灵和物流相关的物品。

### 下界草药

- [x] **晶芽（Crysel）**：生成在下界的植物，会发出微弱的光以及晶化特效。
  - [x] **晶化种子（Crystalization Seed）**：可以用来种植晶芽作物。
  - [x] **晶芽作物**：有4个生长阶段，成熟后可以收获1个晶核和1个晶化种子。
  - [x] **水晶刺（Cryst Spine）**：晶芽的叶子，由于生长在大地的深处，叶片硬的像刺，用于制作晶体植株。
- [x] **炼狱草（Pyraze）**：生成在下界的植物，会发出微弱的光以及火焰特效。
  - [x] **能量种子（Emberseed）**：可以用来种植炼狱草作物。
  - [x] **炼狱草作物**：有4个生长阶段，成熟后可以收获1个燃烧草段和1个能量种子。
  - [x] **燃烧草段（Pyro Node）**：比煤炭更强大的燃料。

### 末地草药

- [x] **星语蔷薇（Stellia）**：生成在末地的植物，会发出微弱的光以及末影星空特效。
  - [x] **神秘种子（Mysterious Seed）**：可以用来种植星语蔷薇作物。
  - [x] **星语蔷薇作物**：有4个生长阶段，成熟后可以收获1个星尘微粒和1个神秘种子。
  - [x] **星尘微粒（Stellar Mote）**：用于制作刷怪的设备（熏香）。

## 食物

- [ ] **星空蛋糕**：昂贵的食物，可以放地上吃，由于璀璨宝石十分坚硬，因此得到了防爆的特性，且由于有了容器，因此可以撸掉，撸掉后记录当前被吃的进度。如果露天（类似信标光柱，透明方块遮挡也行），则如果没吃完，会以固定周期恢复，10秒恢复1块，恢复时，会有紫色末影特效。
- [x] **红樱桃果**：可以种植，可以用来吃，可以改良。
    - [ ] **精灵果**：改良的红樱桃果，更好吃，且可以用来召唤Sylvana。

## 工具

- [x] **织流环（Flowweave Ring）**
  - **调和**：相当于这个模组的扳手，可以用来施法，启动合成，启动炼药，启动附魔，给Sylvana进行绑定等等。
  - **施法**：右键有药水的釜可以将其浸泡在药水内，过一段时间织流环会完全吸收釜里面的药水，药水亲和力会大大提升，此时对着右键不会触发织流环的特殊事件的方块右键时会进行施法，施法后会消耗背包或便携式箱子里面的酿造这个药水时所需的草药，如果没有足够草药，则施法不会成功。施法有三个模式（对着空气或者不会触发效果的方块shift右键可以切换模式，默认为灌注模式）：
    - **灌注模式**：使自己获得对应药水的buff
    - **震荡模式**：发射一道波对命中的地方发生爆炸并使爆炸范围内的生物获得buff，这个爆炸只会发出声音和造成特效，不会有爆炸的效果，爆炸范围为TNT爆炸范围，该波最远飞到64格，该模式施法需要消耗原本草药消耗数量的1.5倍的草药（向下取整）
    - **回响模式**：发射一道波对命中的地方发生爆炸并使爆炸范围内生成对应buff的滞留药水云，这个爆炸只会发出声音和造成特效，不会有爆炸的效果，爆炸范围为TNT爆炸范围，该波最远飞到64格，该模式施法需要消耗原本草药消耗数量的2倍的草药（向下取整）
- [ ] **万象环**：和织流环类似，但是拿在手上的时候有8点攻击力，且施法所需的草药/1.5（向下取整）。
- [ ] **草药师手记本**
  - [ ] **笔记**：主界面，右键打开。相当于这个模组的指南，里面可以看到每个模块的物品的制作方式、用处等等。
  - [ ] **日记**：shift右键打开，内有内置容器栏，可以将日记放进去，放进去后，如果该草药师笔记本在玩家背包里，则会提供给玩家日记提供的buff，但是没装在草药师手记本里不能提供buff。草药师手记本的tooltip会显示已经拥有的日记类型。
    - [ ] **日记效果**：
      - [ ] **旅行日记**：增加携带者的30%/50%/100%移动速度，影响跳跃的速度，自动上1格方块，可以跳上2/3/4格方块，且不限制在空中、水里。
      - [ ] **生存日记**：携带者吃东西可以多1点饥饿值/1点饱食度。
      - [ ] **狩猎日记**：增加携带者0.5/1格的攻击距离。
      - [ ] **采集日记**：未确定。
      - [ ] **劳作日记**：未确定。

  - [ ] **联动**：如果有饰品栏模组时，可以携带在任何部位，如果携带在饰品栏上，按C键可以打开笔记页面，且能享有日记提供的buff。
- [ ] **契约石板**
  - [ ] **物品化**：左键点击可以将生物精灵变为物品形式的精灵之唤，精灵之唤会保留精灵的职业和工作区、目标方块绑定信息。
  - [ ] **绑定工作区和目标方块**：用契约石板右键精灵可以记录正在绑定的精灵，然后开始为这个精灵绑定工作区和目标方块，shift右键方块将方块绑定为工作区，工作区只能有1个；右键方块将方块绑定为工作方块，工作方块可以有64个。右键其他精灵会转换为配置其他精灵的状态，shift右键空气则会退出给当前精灵绑定的状态。

    - **回收模式**：将附近掉落物装入背包。

  - [x] **背负**：除此之外，放在物品栏里的时候会在背上渲染这个模型，相当于背着这个箱子，拿在手上的时候则会显示在手上，而不是背上。如果穿了胸甲，则渲染的时候往外渲染1格，脱掉之后恢复原位。

  - [ ] **璀璨宝石剑**：240点耐久，除了继承对应中级工具的特性外，还能shift右键开启**歼灭**模式，此模式下，攻击时将产生一道大范围横扫的效果，有粒子特效组成的大范围横扫效果，造成8点范围魔法伤害，冷却时间和攻击间隔一样。该伤害命中后，也能触发中级工具的回血效果。

  - [ ] **繁花木弩**：240点耐久，除了继承对应中级工具的特性外，背包里有任意弩匣时，会开启**连射**模式，此模式下，射击0.2秒后会紧接着进行1次射击，此次射击将触发和上一次射击完全相同的行为逻辑（上一次射的是什么，箭矢还是烟花，会造成多少伤害等全部一样）。

## 生产

- [x] **魔法合金砧**：会自动修复的铁砧，降低附魔时的消耗，多次消耗不会增长，并使附魔和修理不会出现过于昂贵
- [x] **水晶灯**：用装有至少8次饮用次数的水壶和萤石等材料合成，合成后水壶会减少8次饮用次数，每个水晶灯会绑定合成时用到的水壶里的药水的效果，但不会保留等级和时间。水晶灯内有1个槽，只能用来放雨露花瓣，能放1组，待机模式下灯身是紫水晶的颜色。放入雨露花瓣后会以每分钟1个的速度消耗雨露花瓣，并开始发光，发出和萤石一样强度的光。发光时，灯身变成绑定药水的颜色（合成时从水壶继承下来的药水颜色），自身为中心、半径25格的区域内的玩家和生物每1.5秒将会获得2秒（也就是恒常）的水晶灯绑定的药水效果，等级为1级，如果药水效果是瞬时的，例如伤害和治疗，则2秒1次该效果。绑定的药水效果需要在两个地方披露，否则多个水晶灯无法区分：物品形态的tooltip显示绑定的药水效果名；灯身颜色即药水颜色。对准时的tooltip只显示内部目前的雨露花瓣数量，不显示药水效果。灯身在材质里是纯白的，颜色一律由代码染色决定：方块待机时染成紫水晶色，方块工作时和物品形态都染成绑定的药水颜色。用雨露花瓣右键放入，空手shift右键取出。可用漏斗，管道自动输入输出。
- [x] **盆栽花盆**：用于栽培晶体植株。没有gui，但是有8个抽象的槽，通过右键交互，一个用来装填土类，只能放1个物品；一个用来装填幼苗，也只能放1个物品；另外6个用来装填草药，可以放每种草药1组。用土类右键可以将土类放进土类槽，此时盆栽里会渲染出对应土类的样子，可以定义可以放什么土类，即使不是真的土类；在有土壤的情况下用幼苗右键可以将幼苗放进幼苗槽，此时盆栽上1格会渲染一个缩小到1格的对应幼苗的材质；用草药右键可以将草药放进草药槽，此时对准盆栽会像草药柜一样渲染出当前盆栽内有的草药的种类和数量，不过盆栽外观不会发生改变。草药槽的草药足够后，植株会消耗所需的草药并开始生长，生长时间较为漫长，生长完后产物会直接掉落到地上。幼苗不会被消耗掉，只会消耗草药。空手shift右键取出草药，用织流环shift右键先后取出幼苗和土壤。因此一个合成配方需要定义：植株幼苗，产物，土壤，生长时间，所需草药，渲染模型。可用漏斗，管道自动输入输出。

## 生物

### 友好生物

- [ ] **精灵（Sylvana）**：自动化物流助手
  - [ ] **生成**：使用精灵果在石柱上供奉后生成，生成时的默认职业为流浪者，且不会四处走动而是待在原地。可以用契约石板变成物品形态的精灵，打死什么都不掉
  - [ ] **绑定职业**：用职业勋章右键精灵可以将精灵绑定对应职业，此时精灵胸前会渲染职业勋章的材质纹理。无论该精灵有没有职业，用职业勋章右键后都会将该精灵的职业改为职业勋章的对应职业
  - [ ] **黑名单和白名单**：每个职业都可以配置黑名单和白名单，用右键不会有特殊事件的物品和空手右键可以打开配置页面，默认黑名单模式。黑名单模式和白名单模式的时候身上穿的衣服会改变（黑色和白色）
  - [ ] **精灵之唤**：物品形态的精灵，用来叫精灵来帮忙，右键某个方块后放下并将精灵的工作区绑定为这个方块
      - [ ] **流浪者**：默认职业，什么都不会干，只会四处游荡
      - [ ] **搬运工**：将工作区的物品搬运到目标方块，可以配置黑名单和白名单。手持小箱子
      - [ ] **补给工**：将目标方块的物品放入工作区，可以配置黑名单和白名单。手持小箱子
      - [ ] **园艺师**：当工作区为容器，则将检测附近一定范围内的树叶，如果有，会跑到树叶旁边修建，以缓慢的速度产生树叶和原木（没有树苗，因为后续会制作树叶转换树苗的方法配方），将产物放入容器。手持红樱木剪刀
      - [ ] **采摘工**：当工作区为容器，将检查附近一定范围内的作物成熟情况，如果有成熟作物，飞到成熟作物处，将成熟作物返回第一阶段且收获对应数量的成熟作物的收获物。手持剪刀。（或改成如果附近有作物成熟，则作物立刻回到第一阶段且掉落对应数量的成熟作物的收获物，减少逻辑复杂度。）
      - [ ] **收集工**：当工作区为容器，检查附近一定范围内的掉落物，如果有掉落物，则飞过去将其收进容器里
      - [ ] **挖掘工**：当工作区为容器，会去挖掘目标方块并使其掉落物进入容器
- [ ] **草药商人**：本模组的村民，可以用绿宝石换到一些模组里的东西，其中包含花圈等装备，暂定通过符文石砖绑定

### 敌对生物

- [ ] **（小怪名称未确定）**：小怪，会掉落六种草药，但是每种概率都很低。
- [ ] **生命花**：Boss，会掉落多种重要的后期材料。在简单/普通/困难模式下有300/400/500生命值。拥有两个阶段，第一个阶段不会受到伤害，破除后进入第二个阶段。
  - [ ] **含苞**：一朵大型的花朵形态。会在场地上生成根须，根须会对周围玩家和生物造成近战伤害，生命花本体会对附近的玩家和生物造成远程伤害。此阶段根须和生命花本体都不会移动，如果没有玩家处于远程攻击范围，即32格内，所有根须会快速恢复生命值且受到的伤害固定为1，因此玩家必须在近距离进行破除。所有根须都爆掉后生命花会进入**绽放**阶段。
  - [ ] **绽放**：一个和玩家一样体型的人形状态。会使用万象环对玩家造成近战伤害，并在固定时间对32格内的一名玩家发动5次斩击和1次高伤害的散花并瞬移到该玩家的位置。和**含苞**阶段一样，如果没有玩家处于32格内，则会快速恢复生命值且受到的伤害固定为1。
